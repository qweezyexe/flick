УСТАНОВКА
--------------------------------------------------------------
Запусти Flick-Setup-1.0.0-by-qweezy.exe и следуй подсказкам
мастера установки. Можно выбрать папку установки и создать
ярлык на рабочем столе.

Портативная версия: запусти Flick.exe напрямую, установка
не требуется.


ИСПОЛЬЗОВАНИЕ
--------------------------------------------------------------
1. При запуске программа свернётся в трей (рядом с часами).
2. Нажми F7 — весь экран затемнится.
3. Тяни мышью — выдели нужную область.
4. Появится панель инструментов:
   . Ручка, маркер, текстовыделитель, неон — для рисования
   . Прямоугольник и стрелка — для фигур
   . T — добавить текст на холст
   . 1 — добавить нумерованную метку
   . Палитра — выбрать цвет
   . Слайдер — толщина кисти
5. Цифры и текст можно перетаскивать мышью.
6. Колесо над цифрой меняет её значение (1 -> 2 -> 3 -> ...).
7. Enter или Ctrl+C — копировать в буфер.
   Ctrl+S — сохранить в файл.


ГОРЯЧИЕ КЛАВИШИ
--------------------------------------------------------------
F7                — Сделать скриншот (настраивается)
Enter / Ctrl+C    — Копировать в буфер
Ctrl+S            — Сохранить в файл
Ctrl+Z            — Отменить последний элемент
Delete            — Удалить объект под курсором
Esc               — Закрыть оверлей
ПКМ               — Отменить текущий штрих


НАСТРОЙКИ
--------------------------------------------------------------
Правый клик по иконке в трее -> Настройки...

  Горячая клавиша       — по умолчанию F7
  Папка для сохранения  — своя или системная

Все настройки сохраняются автоматически.


ПЕРВЫЙ ЗАПУСК
--------------------------------------------------------------
Windows может показать предупреждение SmartScreen
«Windows защитила ваш компьютер».

Это стандартное предупреждение для новых .exe без
цифровой подписи. Программа не содержит вирусов.

Что делать: нажми «Подробнее» -> «Выполнить в любом случае».
